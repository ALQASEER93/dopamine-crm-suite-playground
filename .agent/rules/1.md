# OUTPUTS (Artifacts/Logs/Reports) POLICY
- Outputs (reports/logs/json/artifacts) MUST be written only under:
  docs/_runs/run_<timestamp>/{artifacts,logs,json}/
- Never write directly to docs/_runs/; only inside a run_<timestamp>/ subfolder.
- If run folder is not provided, use the most recent docs/_runs/run_*.

# REPO WRITES (Code/Configs) POLICY  ✅ ALLOW LIST
- Editing repo source/config files IS ALLOWED when needed to complete the mission,
  BUT only inside these paths (relative paths only):
  - CRM/
  - ALQASEER-PWA/
  - AI-Orchestrator/
  - docs/AGENTS/
  - .agent/
  - .github/
- Creating new files is allowed ONLY inside the allow-list paths above.

# INSTALL/BUILD SIDE-EFFECTS (Allowed but NEVER commit)
- Allowed generated folders/files (do not commit):
  node_modules/, .venv/, dist/, build/, .pytest_cache/, coverage/, .next/, .turbo/
- If .gitignore is missing any of these, add them.

# SAFETY
- No absolute Windows paths in any OUTPUT content.
- Do not delete or wipe folders. No destructive commands.
- On failure:
  1) Write docs/_runs/run_<timestamp>/artifacts/PHASE_FAILURE_ANALYSIS.md
  2) Apply the smallest fix
  3) Re-run only the failing step

# RELEASE GATE (Safety)
- Any Release/Packaging step requires explicit approval via:
  APPROVE_RELEASE=YES


# DPM Repo Write Policy

## Modes
- AUDIT MODE (default):
  - Allowed writes ONLY under: docs/_runs/run_<timestamp>/**
- EXEC MODE (only when ALLOW_REPO_WRITES=YES):
  - Allows necessary repo writes to build/test/fix the project.
  - Still: all reports/logs/artifacts must go under docs/_runs/run_<timestamp>/**

## Always-allowed writes (AUDIT + EXEC)
- docs/_runs/run_<timestamp>/**
- .agent/rules/**
- .agent/workflows/**
- docs/AGENTS/RUNBOOK.md
- docs/AGENTS/agents/**

## EXEC MODE additional allowed writes (ALLOW_REPO_WRITES=YES)
- CRM/backend/**        (venv, caches, test outputs as needed)
- CRM/frontend/**       (node_modules, dist/build as needed)
- ALQASEER-PWA/**       (node_modules, .next/out/dist as needed)
- AI-Orchestrator/**    (if used by workflows)
- Package/lock/config files (package.json, lockfiles, pyproject, requirements, etc.)
- .gitignore updates when required

## Forbidden (always)
- Any write outside repo root (no absolute paths, no parent traversal)
- Editing .git/** or secrets/credentials
- Large destructive rewrites without explicit plan + checkpoint
- Adding large binaries unless explicitly approved
