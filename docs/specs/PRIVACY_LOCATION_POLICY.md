# PRIVACY_LOCATION_POLICY

## Purpose
This policy governs employee location collection for visit tracking and compliance.

## Principles
- Transparency: explain what is collected, when, and why.
- Consent: obtain explicit employee consent before enabling tracking.
- Minimization: collect only what is required for visits and routing.
- Control: allow users to pause/stop tracking outside shifts.

## Consent & Onboarding
- Provide a clear consent screen describing collection and retention.
- Require an explicit opt-in before enabling location tracking.
- Re-confirm consent when policy or scope changes.

## Shift-Based Controls
- Tracking is active only during defined shift hours or when a visit is active.
- Provide an in-app toggle to pause tracking outside shifts.
- Log when tracking is enabled/disabled for auditability.

## Permissions Strategy
- Request foreground location first.
- Request background location only if required and after explaining the use case.
- Provide a path to revoke permissions without blocking non-location features.

## Data Handling
- Store only necessary data (timestamp, accuracy, coordinates).
- Protect data in transit and at rest.
- Retain data according to business/legal needs, then delete.

## Employee Rights
- Access to their own tracking data for the last retention period.
- Clear escalation path for questions or complaints.
